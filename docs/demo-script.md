# AssetLens: demo video script (about 80 seconds)

A narrated version of the automatic `docs/media/demo.mp4`, for a CV or LinkedIn. Record the screen at 1280×720 or 1920×1080 with OBS, or with the Xbox Game Bar (Win+Alt+R). Then record the voice over it, or narrate live. Use the live site and the light theme until shot 8.

**Before recording:**
- Open the live site and visit each page once, so the data is cached and loads instantly.
- Save your Alpha Vantage key on the Stocks & ETFs page.
- Set the browser zoom to 110%.
- Close other tabs and notifications.

**Tips:**
- Move the mouse slowly and pause one second after each click.
- Cut the loading waits in editing. Clipchamp, which comes with Windows, is enough.
- Add the live-demo link and the GitHub link as text in the last 3 seconds.
- Export as MP4. For LinkedIn, also upload subtitles: the narration column works as the subtitle text.
